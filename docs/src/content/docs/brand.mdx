Encore's logo is an original rendition of the Go gopher, peeking over the back of an amber couch with a TV remote. The files live in [`docs/brand/`](https://github.com/nightah/encore/tree/main/docs/brand) in the repository; this page and the site's own logo and favicon use them directly.

## Logo

The full illustration on its dark slate tile, for the README, release pages, social previews and anywhere it can be shown at 96 px or larger. The tile is part of the artwork, so it reads the same on light and dark backgrounds.

There are no separate wordmark, lockup or monochrome versions. Where text is needed beside the mark, write "Encore" in the surrounding typeface.

## Usage

- Write the name capitalised, "Encore", in prose and titles; use lower-case `encore` only where it is typed or spoken: commands, file names, the container name and the Alexa invocation.
- Use the logo above 96 px and the mark below that.
- Keep the artwork as it is: don't recolour, crop off the tile, stretch, rotate or add effects, and leave some clear space around the tile.
- Describe the project as working **with** Kodi, never as part of it or endorsed by it.
- Colours used in the artwork and the web interface: slate tile `#1E2836`, gopher blue `#6ACFE3`, couch amber `#D97706`.
